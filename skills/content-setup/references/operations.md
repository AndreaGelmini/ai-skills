# Operations

| Technical field | Purpose / sufficient when |
|---|---|
| `memory_enabled` | Explicit yes/no to retaining editorial learnings. Findings are advisory and cannot modify approved identity/strategy autonomously. |
| `startup_status` | Explicit yes/no to reporting outstanding work when the guide starts; no background monitor. |
| `tools` | Available media/rendering or publication tools (e.g. n8n), intended use, whether merely available or configured. Never store credentials or webhook secrets. Availability is not permission to run, publish or incur costs. |
| `memory_support_threshold`, `memory_contrary_threshold` | Only if memory is enabled. Offer CLI defaults 5/10; overrides count distinct eligible posts, not repeated captures or proof of causality. |

Local tracking and manual publishing are standard. This increment stores preferences only: it does not provision integrations, publish, start a monitor or implement learning promotion.
