# Editorial profile

Interpret these domains, not a fixed questionnaire. Capture information useful for editorial decisions; nonempty text alone is not sufficiency.

| Document type | Purpose / sufficient when |
|---|---|
| `identity` | Author or brand, role, positioning, relevant experience and interests. Explain whose perspective it is without inventing credentials. Keep private or temporary details only if genuinely needed. |
| `objectives` (strategy) | Desired outcomes, priority and what success means. Distinguish primary goal from secondary outcomes. |
| `audience` | Intended readers, needs, subject familiarity and meaningful segments; know what to explain or assume. |
| `voice` | Tone, register, vocabulary, humor, directness, depth, recurring expressions and anti-patterns. Prefer authentic examples to adjectives; propose a synthesis rather than requiring the user to define a polished voice. |
| `scope` | Themes, viewpoints, boundaries, exclusions and special care. Do not turn interests into mandatory topics or force every idea into a theme. |

## Optional creative context

| Document type | Purpose / sufficient when |
|---|---|
| `rubric` (strategy) | One recurring series: name, purpose, audience or angle, format and cadence when relevant. Treat untested strategies as experiments. |
| `example` | Representative authentic writing or links/relative file references, and what to preserve or avoid if known. Do not infer style from titles alone or attribute invented examples to the author. |
| `visual-identity` | Existing palette, typography, avatar, graphic style, logos, non-negotiable constraints and imported asset references. Optional for text-only use; no vision model required to preserve supplied material. |

Persist one meaningful independently changeable entity per Markdown document. Keep optional unknowns distinct from explicit refusal. The [CLI contract](cli.md) explains how to save documents and import assets.
