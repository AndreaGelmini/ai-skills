# Skill catalog

Proposed names; one responsibility per skill. All independently callable where useful. content-flow is sole general guide. Specialized skills delegate by name, not path into another SKILL.md. No new skill merely for a parameter. Each body aims well below 500 words; English instructions, conversation-language output. Put routing in description, including near misses. Refer to resources only when needed.

| Skill | Responsibility / input | Output / boundary |
|---|---|---|
| content-setup | Inspect workspace, interview missing settings | Approved resumable configuration; no content drafting |
| content-flow | Resolve idea, inspect state, route requested work | Relevant next action or delegated skills; no mandatory pipeline |
| idea-interview | Explore raw input, history, intent and delivery choices | Editable brief with provenance/completeness; no automatic approval |
| to-spine | Organize message from adequate context | Narrative guide, not finished post |
| to-spine-sequence | Plan episode angles and cadence, reuse to-spine | Main/derived spines and plan, upfront/progressive |
| to-draft | Write native content from sufficient context | Versioned draft; no required spine |
| to-draft-with-spine | Interpret selected spine and constraints, delegate to-draft | Aligned draft with exact dependencies; no duplicated writing rules |
| to-media | Propose visual direction, composition, delegate/import media | Composition spec and actual assets if available; no invented render |
| consistency-check | Review intent, voice, format, facts, coherence, visual quality | Findings; corrected version only on request; humanizer pass |
| to-content | Assemble approved version and assets | Validated publish package, not publication |
| to-publish | Prepare/export and record publication, optional configured handoff | Receipt/status; never claim success without confirmation |
| to-analytics | Ingest source and describe one post against fixed criteria | Structured snapshot and evidence; no causal inference |
| content-patterns | Compare multiple posts and detect patterns | Scoped observations, hypotheses, experiments, uncertainty |
| content-learnings | Synthesize recommendations and update optional learning memory | Advisory findings; script applies thresholds; no autonomous identity change |

content-status is a deterministic command, not a mandatory skill; content-flow can summarize it. Save/version/resolve/index are shared scripts rather than prompts. Hook/CTA/headline techniques are reference sections, not standalone MVP skills. No separate social provider or renderer skills until actual integration warrants them.

## Authoring gate

Use Andrea Skill Builder / repository create-skill conventions. One job, high semantic density, no generic best-practice filler. Exact sequences only for fragile/irreversible actions. Skill-local scripts in <skill>/scripts/, common scripts in parent scripts/; same for references/assets. Validate all metadata and Markdown links using existing validators. Test real activation and packaging (including shared resources), then revise actual failure modes. Do not copy source projects wholesale.
